# Showcase Evaluation — Criterion-to-Evidence Mapping

**Audience:** MoICT&NG Government Systems Prototype Showcase panel; MoH / NITA-U technical leads conducting independent verification.
**Last reviewed:** 2026-05-25.
**Submission target:** Showcase, 25 June 2026.

This document is the **panel-facing index**: it lists every published evaluation criterion, names the document(s) and code path(s) where evidence lives, summarises the headline metric, and provides a one-line verification command a reviewer can run.

Stable IDs: `EV-CC-NN` where `CC` is the criterion code and `NN` is the sub-criterion. They are referenced from [TEAM.md](./TEAM.md), [IMPACT_EVIDENCE.md](./IMPACT_EVIDENCE.md), and the submission cover letter.

## How to use this document as a panel reviewer

1. **Read top-to-bottom.** Each criterion has a one-line definition, a sub-criterion table, and verification commands. Approximate time: 30 minutes for a full read.
2. **Spot-verify** at least one row per criterion using the *Verification* column. The commands assume a freshly cloned repo + `make stack && make seed && make backend && make frontend`.
3. **Cross-reference** any claim back to its primary evidence document. Every primary evidence document has its own `Last reviewed:` line and stable IDs.
4. **Where evidence is pending**, the row points to the doc that owns its capture. Pending items are:
    - **EV-SC-08 (pentest report):** scheduled per [SECURITY.md §"Penetration testing & vulnerability management"](./SECURITY.md). Vendor and dates declared in the submission cover letter.
    - **EV-UA-03 / EV-UA-04 (Lighthouse / axe-core):** captured against the production build immediately before submission and archived under `lighthouse-results/` and `axe-results/`. Methodology in [IMPACT_EVIDENCE.md §6](./IMPACT_EVIDENCE.md#6-usability--accessibility-results).
    - **EV-LV-06 (measured pilot impact):** captured during the pilot per [IMPACT_EVIDENCE.md §3–§5](./IMPACT_EVIDENCE.md#3-baselines-cited-public-sources). The Showcase submission documents the *methodology* and *commitments*; measured outcomes follow pilot start.
